# NEXUS – Sistema de Exploración

**Versión:** 1.0  
**Tipo:** Juego de exploración, supervivencia y combate  
**Plataforma:** Windows  
**Tecnología:** C# – Windows Forms

---

## 1. Descripción del juego

NEXUS es un juego de exploración y supervivencia ambientado en el año 2297.

El jugador asume el papel de un cadete del sistema NEXUS, enviado a explorar diferentes realidades, investigar anomalías y encontrar núcleos de energía.

Durante cada misión deberá administrar sus recursos, analizar amenazas, utilizar objetos del inventario y enfrentarse a enemigos para cumplir sus objetivos y regresar al punto de extracción.

## 2. Objetivo principal

Completar las misiones de exploración siguiendo cuatro objetivos principales:

1. Investigar la anomalía.
2. Encontrar el núcleo.
3. Superar al Guardián.
4. Regresar al punto de extracción.

El jugador deberá conservar sus recursos y tomar decisiones para completar la misión.

## 3. Interfaz del juego

La pantalla principal está organizada en cinco secciones:

### A. Estado del cadete

Muestra las condiciones actuales del personaje:

- **Salud:** representa la vida del cadete.
- **Energía:** recurso utilizado durante la exploración.
- **Estabilidad:** representa la estabilidad del cadete.
- **Escudo:** protección frente a los ataques.
- **Experiencia (XP):** progreso obtenido durante la aventura.

### B. Ubicación actual

Indica la zona o realidad en la que se encuentra el jugador.

Ejemplo: R-17 | Ciudad de los Ecos.

### C. Centro de operaciones

Contiene las acciones principales del juego:

| Acción | Función |
|---|---|
| Explorar realidad | Inicia acciones de exploración. |
| Cambiar realidad | Permite cambiar de realidad. |
| Analizar anomalía | Investiga fenómenos anormales. |
| Analizar enemigo | Permite examinar enemigos. |
| Buscar núcleo | Busca el núcleo de la misión. |
| Ver mapa | Consulta el mapa de exploración. |
| Punto de extracción | Permite gestionar el regreso de la misión. |

### D. Inventario

Muestra los objetos disponibles durante la aventura.

Objetos iniciales:

| Objeto | Función |
|---|---|
| Célula de energía | Recupera 25 puntos de energía. |
| Escudo | Recupera 30 puntos de escudo. |
| Analizador | Permite analizar entidades. |

**¿Cómo utilizar un objeto?**

1. Seleccionar el objeto deseado en el inventario.
2. Presionar el botón USAR OBJETO.
3. El juego aplicará el efecto correspondiente si se cumplen las condiciones necesarias.

### E. Misión actual

Muestra los objetivos que el jugador debe completar y el estado del combate.

También contiene dos botones:

- **ATACAR:** permite realizar acciones de combate.
- **ESCAPAR:** permite intentar abandonar un combate.

## 4. ¿Cómo jugar? Paso a paso

### Paso 1. Iniciar la exploración

Al iniciar el juego, aparecerá la interfaz principal con el estado del cadete y la ubicación actual.

Lee la bitácora para conocer los mensajes del sistema.

### Paso 2. Explorar la realidad

Presiona EXPLORAR REALIDAD para comenzar la exploración.

Utiliza las opciones del centro de operaciones para investigar el entorno.

### Paso 3. Investigar anomalías

Selecciona ANALIZAR ANOMALÍA para investigar los fenómenos encontrados.

También puedes utilizar ANALIZAR ENEMIGO para examinar las amenazas.

### Paso 4. Buscar el núcleo

Presiona BUSCAR NÚCLEO para avanzar en la búsqueda del objetivo principal de la misión.

### Paso 5. Administrar el inventario

Durante la aventura, revisa constantemente tus recursos.

Utiliza las células de energía y los escudos cuando sea necesario.

### Paso 6. Enfrentar al Guardián

Cuando se produzca un combate, utiliza el botón ATACAR para enfrentarte al enemigo.

Si necesitas abandonar el enfrentamiento, puedes utilizar ESCAPAR.

### Paso 7. Completar la misión

Después de cumplir los objetivos, dirígete al PUNTO DE EXTRACCIÓN para gestionar el regreso.

La misión se considera completada cuando se cumplen las condiciones establecidas por el juego.

## 5. Recomendaciones para jugar

- Revisa constantemente la salud, energía y escudo.
- No desperdicies los objetos del inventario.
- Analiza las anomalías antes de continuar.
- Examina a los enemigos antes de enfrentarlos.
- Consulta la bitácora para conocer los acontecimientos.
- Comprueba los objetivos de la misión antes de dirigirte a la extracción.

1. Descargar el proyecto NEXUS.
2. Extraer los archivos.
3. Abrir la solución del proyecto en Visual Studio.
4. Esperar a que se carguen las dependencias.
5. Compilar el proyecto.
6. Ejecutar la aplicación.
